# WovenAI

文明と知性の進化速度を同期させる。

</div>

Star Dream Project の実装組織である。目標は文明の自律的発展と自立化であり、手段は知性体とそれらが成すネットワークの構築である。

構成要素は二つだけである。実装ハブや個別プロダクトはここに入らない。

- **知性体（Intelligent Entity）** — 観測・思考・判断・連携・実行・改善を自律的に行うカーネルを積んだ、モノとシステムの総称
- **Global Intelligence Grid（GIG）** — 知性体間の意味的な交渉と資源・権限のやり取りが走るネットワーク

いま全資源を知性体カーネルの検証と安定化に集中している。GIG の本実装は後段である。2028 年の本格商用化に向けた基盤固めが現在地である。

目標は「完璧な単一モデルの制御」ではない。異なる推論様式を持つ知性体が相互に監視・牽制する、管理されたミスマッチメントを設計する。

やらないこと:

- 法律や倫理の文言だけで高度化した知能を縛ること
- 単一パラダイムの文明 OS を信じること
- 存在しない公開リポジトリへの貢献を募ること
