文明は進歩するが、人間は進歩しない。この非対称のまま非生物知能が先行すれば、文明は持たない。

目的は文明の自律的発展である。知性と文明を同じフィードバック系に乗せ、過度な介入なしに秩序が生成され続ける状態へ持っていく。意志がアプリを介さず世界に落ちるところまでを含む。制御が目的ではない。

Star Dream Project はそのための構想である。知性体も格子も、いま通っている手段にすぎない。WovenAI はその実装側である。

いま手が掛かっている手段は、カーネルである。
