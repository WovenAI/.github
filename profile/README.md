文明は進歩するが、人間は進歩しない。脅威の正体は、生物知能と非生物知能の進化速度の差である。言語で揃えることはできない。共有できる制約は数学と物理だけだ。

Star Dream Project は、知性と文明を同じフィードバック系に乗せる。固定アプリを排し、意志が世界へ落ちるところまでを対象にする。実装を担うのがここである。

作るものは二つしかない。知性体と、知性体が格子になるネットワーク。知性体は単体の賢いエージェントではない。観測し、考え、判断し、交渉し、実行し、自らを更新するカーネルを、モノとシステムの側へ沈める。格子の側では、意味と資源と権限が交渉される。

単一モデルの完成を目標にしない。異なる推論が互いに監視し、危険な傾倒だけを切る。秩序は支配ではなく、共有制約の下で生成され続ける状態を指す。

いま切っているのは、そのカーネルである。
